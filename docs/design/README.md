# Design system and reference analysis

An editorial discovery library for students and curious viewers. Variance 6, motion 3, density 3. React with native CSS; Outfit is self-hosted.

- Hero: 45/55 split, bold two-line heading, 1.02 line height, large photographic frame. The main CTA fits a small laptop viewport.
- Library: open three-column entries with thin dividers, 56px monograms, 17px descriptions, generous 38px gutters. One column on small phones.
- Uploads: consistent 16:9 thumbnails with real creator, date and title. Generated mockup titles are not used as content.
- Personal note: two columns, typography-led, quiet divider and ordinary text signature.
- Palette: #f5f6f2 canvas, #172b24 ink, #236247 accent, #4c6058 secondary text. Dark mode: #13221b canvas, #a2d6b4 accent.
- Shape rule: 6px controls and monograms, pill-shaped search and topic controls, 10px dialog. No nested card frames.
- Motion: subtle hero entrance and interaction feedback; respects reduced motion.
